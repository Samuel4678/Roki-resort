# ROKI Resort website
Static site for GitHub Pages (no build step).

**Publish:** upload this folder to a GitHub repo (keep `.nojekyll`) → Settings → Pages → Deploy from branch → `main` / root.

**Contact details:** open `config.js` and fill in `phone`, `whatsapp` (e.g. `2547XXXXXXXX`) and `email`. They appear on the site automatically and booking/enquiry buttons send to WhatsApp (or email, or Facebook if blank).

**Photos:** replace files in `images/` keeping the same names.
